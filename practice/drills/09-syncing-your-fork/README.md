# Exercise 09: Bring Feedback Into the Work

## Task

1. Update your branch with the latest project notes.
2. Read new feedback or decisions since your experiment began.
3. Resolve any differences deliberately.
4. Record whether the new context changes your experiment.
5. Update the roadmap or decision log if the next step changed.

## Check yourself

The project record reflects both the experiment and the context learned while it was underway.
