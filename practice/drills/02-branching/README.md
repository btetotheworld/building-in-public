# Exercise 02: Isolate an Experiment

## Task

1. Create a branch named `experiment/short-name`.
2. Add one proposed change to `scratch.txt`.
3. Commit it with a message that explains the experiment.
4. Compare the branch with `main`.
5. Decide whether the change is ready to share, needs evidence, or should be dropped.

## Check yourself

The experiment should be easy to separate from the stable project record.
