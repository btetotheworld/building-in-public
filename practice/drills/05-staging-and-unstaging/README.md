# Exercise 05: Keep an Update Focused

## Task

1. Add one observation under Section A in `draft.txt`.
2. Add one unrelated idea under Section B.
3. Stage only the observation first.
4. Review the staged diff as a public update.
5. Unstage it, then decide whether the two ideas belong in separate changes.

## Check yourself

The final commit contains one coherent update, or clearly explains why the ideas belong together.
