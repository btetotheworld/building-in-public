# Exercise 03: Resolve Competing Interpretations

## Task

1. On one branch, change the first line of `shared.txt` to describe the project in one way.
2. On another branch, change the same line to describe it differently.
3. Merge the branches and inspect the conflict.
4. Resolve it by choosing the wording that is clearest and best supported.
5. Record the reason for the choice in the merge commit or a nearby note.

## Check yourself

The final file has one clear statement and no conflict markers. The decision is explainable.
