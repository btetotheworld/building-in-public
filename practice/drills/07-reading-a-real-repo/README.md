# Exercise 07: Study Another Public Project

## Task

Choose an active public project with a clear audience. Read its README, contribution guide, changelog, and recent discussions. Record your observations in `answers.md`:

1. What does the project promise?
2. How does it show current status or progress?
3. Where does it invite feedback?
4. What evidence does it use to explain decisions?
5. What would you borrow or avoid here?

## Check yourself

Your notes describe communication choices and their effect, not just the project's features.
