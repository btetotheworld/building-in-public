# Current State

This page is the honest snapshot of the project. Update it when the direction, evidence, or next step changes.

## What we are building

We are building a repeatable practice for turning early ideas into useful, public work. The repository holds the decisions and experiments that make that practice visible.

## Where things stand

| Question | Current answer |
| --- | --- |
| What is the focus? | Small experiments, documented clearly enough for someone else to follow. |
| What has shipped? | The repository structure, public notes, contribution paths, and starter experiments. |
| What are we learning? | Consistent documentation makes feedback more specific and easier to act on. |
| What is uncertain? | Which format best helps readers follow progress without creating busywork. |
| What is next? | Run a small experiment, publish the result, and revise the process from evidence. |

## Update this page when

- the project focus changes;

- new evidence changes a belief; or
- the next milestone becomes clearer.

Keep the language concrete. Say what happened, not what was intended to happen.
