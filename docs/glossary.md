# Glossary

**Build in public** — sharing the process, evidence, decisions, and lessons while work is still underway.

**Decision log** — a dated record of context, options, a choice, and the conditions that might change it.

**Evidence** — an observation or artifact that supports or challenges a belief.

**Experiment** — a small, deliberate test designed to reduce uncertainty.

**Feedback** — information from another person, a user, or an observed behavior that can improve the next decision.

**Failure** — an experiment result that did not support the intended outcome; still useful when documented honestly.

**Hypothesis** — a belief stated clearly enough to test.

**Learning loop** — the cycle of choosing a question, trying something, observing the result, and deciding what happens next.

**Milestone** — a meaningful state change, not merely a list of tasks completed.

**Roadmap** — a current view of likely next steps, subject to evidence and revision.

**Signal** — a measurable or observable indication that helps evaluate progress.

**Snapshot** — a concise description of the project's current state.

**Work in progress** — unfinished work that is shared to invite context, feedback, or collaboration.
