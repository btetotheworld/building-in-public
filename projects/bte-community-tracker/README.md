# BTE Community Tracker

BTE Community Tracker is a community platform for turning real problems into public, collaborative projects during BTE Build Sessions.

## Why BTE Is Building It

BTE Build Sessions bring community members together to identify meaningful problems, form teams, build solutions, and document the outcomes in public. This repository is both the home of the platform and an example of that collaborative process.

## Product Flow

```text
Real problem -> Build Session -> Team -> Project -> GitHub repository -> Contributions -> Project outcome
```

The platform is organized around members, sessions, teams, problems, projects, and contributions. GitHub remains the source of truth for development activity.

## Current Build Session

The current session information will be documented here as the community selects a problem, forms a team, and defines the project outcome.

## How to Contribute

Use GitHub Issues to discuss and select work. Create a focused branch, open a Pull Request, request review, and merge approved changes. See [docs/contribution-guide.md](docs/contribution-guide.md) for the contribution workflow.
